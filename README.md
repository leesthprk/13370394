### 2｜關於我 (About Me)

- **學歷背景：** 就讀學校：台南應用科技大學；就讀科系：多媒體動畫系。
- **自我介紹：** 我對於遊戲設計以及電影初期美術感興趣，喜歡研究虛擬角色的設計、美術分鏡等以及探索何運用畫面帶給觀眾或玩家強烈沉浸感。

### 3｜興趣與專長 (Interests & Skills)
- **科幻影視：** 未來科技架構、奇幻世界觀等。
- **音樂熱愛（唱片封套與黑膠互動）：**
  - 熱衷於千禧年的龐克搖滾，喜歡的樂團：**我的另類羅曼史**、**穿透面紗**、**打倒男孩**。
  - 載入 `album cover/` 資料夾中 3 張封面圖片。
  - 打造擬真黑膠唱片（Vinyl Record）抽出滑動與音軌旋轉效果。
  - 提供**「展開展示 [SPREAD]」**與**「摺疊堆疊 [FOLD / STACK]」**兩種檢視模式切換。
- **遊戲喜好：** 動作角色扮演遊戲分析（空洞騎士、臥龍蒼天隕落、人中之龍）。
- **專長能力：** 影音製作、基本繪圖能力（搭配專長儀表進度條與狀態指示燈）。

### 4｜學習成果與作品集 (Works & Portfolio)
- **完整展示：** 檢索並收錄 `works/` 資料夾內全部 7 張創作作品（包含橫幅、方幅與直幅海報插畫）。
- **摺疊堆疊展示 (Folded / Stacked View)：**
  - 作品展示預設採用**「摺疊堆疊」**互動展台，卡片以 3D 傾角與層疊方式優雅呈現。
  - 支援「◀ 上一件」與「下一件 ▶」快速切換抽檢作品，並可在摺疊堆疊與展開網格間自由切換。
  - 點選任一卡片可抽檢置頂，再次點擊即可進入全螢幕燈箱。
- **全螢幕燈箱（Lightbox Modal）：** 點擊作品放大為全螢幕高解析度檢視，支援**「上一張 / 下一張」**按鈕、作品計數器（1 / 7），以及鍵盤 `←`、`→` 與 `Esc` 快速操作。
